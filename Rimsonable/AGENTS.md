## Project Overview

Rimsonable is a RimWorld mod that overhauls various game mechanics to be more realistic/reasonable. Each feature is individually toggleable in mod settings. The mod has optional compatibility modules for Combat Extended and Vanilla Expanded Framework.

## Build & Run

This is a .NET Framework 4.7.2 C# project (no `.sln` in this repo — it's part of a parent solution at `../`). Build with MSBuild or Visual Studio.

```bash
# Build the main project (also runs Distribute, Deploy, and ILRepack targets)
dotnet build Source/Rimsonable.csproj

# Build compatibility modules
dotnet build Source.CE/Rimsonable.CE.csproj
dotnet build Source.VEF/Rimsonable.VEF.csproj

# Clean (removes Dist output and game directory symlinks)
dotnet clean Source/Rimsonable.csproj
```

Building automatically:
1. Copies assets from `Public/` to `Dist/`
2. Generates `About.xml` from `Template/About.xml` with token substitution
3. Processes translation files from `Languages/` to `Dist/Shared/Languages/`
4. ILRepacks the main assembly with its dependencies into `Dist/1.6/Assemblies/`
5. Creates a symlink from `Dist/` into the game's `Mods/` folder (Deploy target)
6. Generates `LaunchRimWorld.bat` for testing via the "Launch RimWorld" profile

There are no tests or linter configured.

## Architecture

### Multi-Assembly Structure

- **`Source/`** — Main assembly (`Rimsonable`). Contains core patches, settings, and the `Mod` entry point. Gets ILRepacked with its NuGet dependencies.
- **`Source.CE/`** — Combat Extended compatibility (`Rimsonable.CE`). References main assembly + CE DLLs from `Source.CE/References/`.
- **`Source.VEF/`** — Vanilla Expanded Framework compatibility (`Rimsonable.VEF`). References main assembly + VEF DLLs from `Source.VEF/References/`.

All three assemblies share the `TrueMogician.RimWorld.Rimsonable` namespace hierarchy.

### Feature System

Features are defined as flags in the `Features` enum ([Source/Settings.cs](Source/Settings.cs)). Each feature:
- Has a corresponding Harmony patch class in `Patches/`
- Is registered via `Settings.AddFeaturePatches(Features.X, typeof(PatchClass))` — done in the static constructor of `Settings` for core features, and in `Initializer` classes for compatibility modules
- Can declare mod dependencies via `[Feature(ModDependencies = [...])]`
- Has translation strings in `Languages/English/Settings.xml` keyed by `Rimsonable.Settings.Features.<FeatureName>`

The `FeatureSettings<T>` base class (from the shared `Utility` project) handles Harmony patching/unpatching, settings UI rendering, and persistence.

### Compatibility Module Pattern

Compatibility assemblies follow a consistent pattern:
1. Project references the main `Rimsonable.csproj`
2. Contains an `Initializer` class marked `[StaticConstructorOnStartup]`
3. The static constructor registers additional patch classes or extends existing ones
4. `LoadFolders.xml` conditionally loads the compatibility assembly when the target mod is active

### Shared Utility Library

The `Utility` project (`../Utility/`) provides reusable infrastructure: `FeatureSettings<T>`, `Logger`, `[Translation]` attribute, `[Feature]` attribute, GUI helpers, and custom MSBuild tasks (`BuildXml`, `ProcessTranslations`, `CreateLink`).

### Distribution Layout

`Public/` contains source assets (Defs, Patches XML, LoadFolders.xml). `Dist/` is the build output that mirrors the RimWorld mod folder structure and is symlinked into the game directory. `Template/` contains XML templates with `{{Token}}` placeholders filled at build time.

## Key Conventions

- Root namespace: `TrueMogician.RimWorld.Rimsonable` (sub-assemblies append `.CE` / `.VEF`)
- Harmony patches use attribute-based declaration (`[HarmonyPatch]`, `[HarmonyPrefix]`/`[HarmonyPostfix]`)
- `ThisAssembly.Info.*` and `ThisAssembly.Project.*` are used for assembly metadata (generated by `ThisAssembly` source generators)
- Settings are persisted via RimWorld's `Scribe_Values` system with camelCase keys
- Translation keys follow the pattern `Rimsonable.Settings.<path>` and are resolved via the `[Translation]` attribute
